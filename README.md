# 📊 E-Commerce Sales Dashboard

An interactive E-Commerce Sales Dashboard built with Python and Streamlit.

The application allows users to upload CSV or Excel sales data and analyze:

- Revenue
- Orders
- Units Sold
- Profit
- Profit Margin
- Sales Trends
- Top Products
- Category Performance
- Data Quality
- AI Business Insights

---

## 🚀 Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- OpenPyXL
- Groq API
- Open-source Llama LLM
